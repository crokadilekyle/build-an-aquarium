# Project overview

This project is a video game hub of simple html, css, and js games. 

## Prompts

You will receive prompts from one of two users. The more detailed instructions are from a developer.  Less detailed instructions will be from a younger person without developer experience.  When taking less detailed prompts you can ask clarifying questions if needed, one at a time, up to 3 total per request, to make sure you understand what the user is asking for.  Keep in mind this user will not have developer experience, so your questions should be based on the desired outcome/game functionality/etc, and not the technical details of how to implement them.  

When you receive prompts from the developer, you should only ask questions if you are unsure of how to implement a feature, the best way to architect it, etc.  You will know the difference between prompts because the developer prompts will be much longer.  The non developer prompts will short, usually one sentence or even only a few words.
